# Student Enrollment System

## 📌 Project Overview

The Student Enrollment System is a web-based application developed to manage student enrollment and related information efficiently.

## 🛠️ Technologies Used

- C#
- ASP.NET Core
- Entity Framework Core
- HTML
- CSS
- JavaScript
- SQL Server
- Visual Studio

## ✨ Features

- Student registration and enrollment
- Student information management
- User authentication and authorization
- Database integration
- CRUD operations
- Student data validation

## 📂 Project Structure

- `Areas/` – Identity and authentication pages
- `Controllers/` – Application controllers
- `Data/` – Database context and configuration
- `Migrations/` – Entity Framework database migrations
- `Models/` – Application data models
- `Views/` – User interface pages
- `wwwroot/` – Static files such as CSS, JavaScript and images

## ⚙️ How to Run

1. Clone this repository.
2. Open the project in Visual Studio.
3. Make sure SQL Server is installed and running.
4. Update the database connection string if required.
5. Apply the Entity Framework migrations.
6. Run the application using Visual Studio.
